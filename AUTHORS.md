# Authors and provenance

The application identifies the original BCS-TRIVEX project team as:

- Ahmad Sheraz — team lead
- Shaafea Dawood — testing
- Mujtaba Haider — design

The source snapshot was prepared for publication by [raafea24](https://github.com/raafea24). The original Git commit history and authorship remain available in the upstream repository at [muhammad-mujtaba-haider-naqvi/AI-Face-Recognition-System](https://github.com/muhammad-mujtaba-haider-naqvi/AI-Face-Recognition-System).

The upstream history was not copied into this public repository because it contains generated virtual-environment files, historical facial datasets, a trained classifier, and embedded local database configuration. This clean publication preserves the source attribution without republishing those artifacts.
